## Apps

- 🎮 **[ChargeCast](https://sakuradevjp.github.io/ChargeCast-notes/)** — Stream Android games to PC via USB. No capture card. Stays charged.
- 🔊 **[AudioFixer](https://sakuradevjp.github.io/AudioFixer-notes/)** — Lossless video volume booster. Normalize or amplify without re-encoding.
- 📱 **[NotiKeep](https://sakuradevjp.github.io/notikeep-notes/)** — Save every notification for Android. Ad-free, all on-device.
- 🪟 **[Split Screen Launcher](https://sakuradevjp.github.io/split-screen-launcher-notes/)** — App pair tool that still works on Android 15/16.

## About this repo

This is a single static page (`index.html`) served via GitHub Pages.

- Light/dark adaptive theme
- Schema.org structured data for each app
- IndexNow integration for instant Bing notifications
- Sitemap index referencing all sub-projects

If you want to know more about the developer or the apps, the live site is the place to be.
